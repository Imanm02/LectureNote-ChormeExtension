Your data choice

Allow local note capture?

Lecture Notes needs your permission before it reads page details or handles saved note data.

  • When you open Quick capture or choose Capture selection, it can read selected text, the page title, and the page URL from the current tab.
  • It stores notes, drafts, settings, and pending captures in Chrome storage in this profile.
  • It does not send this data to a server.

Nothing is read until you choose Allow local note capture. You can close this page without accepting.

Read the privacy notice

Clear all stored extension data?

This permanently removes notes, drafts, settings, and captured selections from this Chrome profile. The data is not opened first.
